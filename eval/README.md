# Alignment eval — стенд сравнения моделей авторасстановки

Фикстуры и скрипты для проверки и сравнения моделей forced alignment
(авторасстановка таймингов слогов по вокалу). Фикстуры извлечены из
реальных `.kfn` (см. `extract-fixtures.mjs`) и **хранятся в репозитории** —
это ground truth для тюнинга и будущих моделей.

## Фикстуры

| Песня | Слогов | vocal.mp3 | Примечание |
|---|---|---|---|
| `kiri` (Monoral — Kiri) | 180 | ⚠ только подпевки | автор KFN вшил бэк-хармонии, lead-стем отбросил — для выравнивания лида НЕ годится (см. ниже) |
| `dreaming-wild` (Klahr & KEV) | 338 | ✗ | в KFN только инструментал — текст/эталон для будущих тестов |

Структура: `fixtures/<song>/lyrics.txt` (текст с разметкой слогов KFN),
`reference.json` (`[{text, sep, startMs}]` по слогам — эталон), `vocal.mp3`.

Перегенерация: `node eval/extract-fixtures.mjs` (нужны файлы в `kfn/`).

**Проверка пригодности аудио**: `node eval/verify-stem.mjs` — сравнивает
энергию стема в моменты эталонных слов со случайными моментами. Для kiri
ratio = 0.59 (< 1: стем молчит там, где поются слова) — подпись «Backing
Vocals» оказалась честной, это только хармонии.

## Запуск бенчмарка

```bash
npm run dev                                                    # dev-сервер на :5173 (обязателен)
node eval/run-align-eval.mjs --audio kfn/Kiri-lead.mp3         # lead-стем песни
node eval/run-align-eval.mjs --audio kfn/Kiri-original.mp3 --separate  # полный цикл
```

`--audio` — путь (от корня репо) к оригиналу песни или lead-стему,
положенному в `kfn/` (gitignored). `--separate` — полный пользовательский
цикл: оригинал → наш Mel-RoFormer → лид → выравнивание (первый запуск качает
~700 МБ, несколько минут инференса). Без `--audio` используется фикстурный
vocal.mp3 (для kiri — только смоук-прогон: метрики будут мусорными, лида там нет).

Сценарий в реальном браузере: аудио → роль, сырой текст → «✂ Разбить на
слоги», «⏱» → авторасстановка. Сравнение — **пословно** (слогоделение KFN ≠
наше, слова совпадают): median/mean/p90 отклонения, % слов в пределах
100/250/500 мс, глобальный сдвиг.

Ключи: `--model <id>` (из `MODEL_REGISTRY`), `--song kiri`,
`--strategy chars|proportional`. Первый запуск качает модель выравнивания
(~190 МБ) — таймаут 10 минут. Нужен WebGPU (Chrome). Результаты:
`eval/results/*.json` (gitignored).

## Добавление модели

1. Добавьте запись в `MODEL_REGISTRY` (`run-align-eval.mjs`): URL
   self-contained ONNX (wav2vec2-CTC с тем же 32-токенным словарём — иначе
   понадобится своя карта токенов в `src/lib/alignment/ctc.ts`) + имя кэша.
2. Прогоните `node eval/run-align-eval.mjs --audio <вокал> --model <id>` и
   сравните метрики с текущей моделью.

Кандидаты на будущее: русская xlsr-53-russian ONNX (Cyrillic CTC), крупные
английские wav2vec2-large-960h (точнее, но тяжелее).
