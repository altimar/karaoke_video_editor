# UI и состояние

## Store (`src/state/store.ts`)

Мини-реактивный стор — единственный источник истины:
- `getProject()` — текущий проект.
- `mutate(fn)` — изменить проект in-place, уведомить подписчиков.
- `setProject(p)` — заменить проект (загрузка); клонирует.
- `subscribe(fn)` — подписка на изменения.

Все UI-компоненты подписаны на store и обновляются при любом изменении.

## Модель: дорожки

Проект содержит массив дорожек разных типов (`Project.tracks: Track[]`). `Track` — дискриминированный union с полем `type`: текстовые (`TextTrack`: `lines`, `style`, `rendererSettings`) и аудио (`AudioTrack`: `audioFileName`, `volumeAutomation`). Ровно одна дорожка активна (`Project.activeTrackId`) — любого типа. Общий фон (`Background`) живёт на уровне проекта. Разрешение/aspect (`width`/`height`) и `fps` тоже хранятся в модели (`Project`), но в UI не редактируются: разрешение — константа авторинга (на нём рисуется превью и считается aspect-ratio экспорта), а `fps` выбирается в диалоге экспорта.

Хелперы (`src/types.ts`):
- `getActiveTrack(project)` — активная дорожка (любого типа; фолбэк на `tracks[0]`).
- `getActiveTextTrack(project)` — активная текстовая дорожка или `null` (для text-only потребителей).
- `getActiveAudioTrack(project)` — активная/первая аудиодорожка или `null`.
- `getTextTracks(project)` / `getAudioTracks(project)` — фильтр по типу.
- `createTextTrack(name, lines?)` / `createAudioTrack(name, audioFileName)` — фабрики дорожек.

## Критичный паттерн: «построил один раз — обновляю in-place»

Панель стилей (`stylePanel.ts`) строится **один раз**. При изменении store контролы обновляют свои значения через setter-функции (`field.set(v)`), а **не пересоздают DOM**. Это обязательно — иначе перетаскивание слайдеров обрывается (DOM-узел уничтожается под курсором).

Условные блоки (зависящие от `bgType`) пересоздаются **только при смене условия**, а не при каждом изменении значения.

**Per-track карточки** (шрифт, цвета, обводка, раскладка) перестраиваются **только при смене `activeTrackId` или режима раскладки (`layout`)** — не при каждой правке значения. Поэтому переключение дорожки (или режима) перевязывает поля, а редактирование внутри дорожки не рвет drag слайдеров.

## Разделение настроек в StylePanel

- **Per-track** (активная дорожка): шрифт, размер, межстрочный, выравнивание, цвета заливки (активная/неактивная), обводка (толщина + цвета границ активная/неактивная), свечение, раскладка (режим `layout` + настройки выбранного рендерера). Также поле «Название дорожки». Панель показывает **ИЛИ** настройки дорожки, **ИЛИ** настройки фона: клик по шапке «Фон» на таймлайне («выбор» псевдостроки, шапка подсвечивается) показывает карточку «Фон» и прячет карточки дорожки; клик по шапке любой дорожки (даже уже активной) возвращает панель дорожки (колбэки `TimelineOptions.onBackgroundSelected/onTrackSelected`, плюс fallback в `syncFromStore` при внешней смене `activeTrackId`). На мобильных выбор «Фон» сразу открывает props-sheet. Карточка «Фон» (бывш. «Фон (общий)»): тип, **всегда видимая** кнопка «Загрузить картинку или MP4…» (общая логика `ui/bgFile.ts: applyBgFile` — грузит и таймлайн-строка, и панель; загрузка сама переключает тип), вписывание (для картинки/видео), цвет/градиент. Числовые поля (размер, межстрочный, обводка, свечение, настройки рендереров) — **одной строкой**: заголовок | слайдер | моноширинное значение. **Выравнивание** — тоже одной строкой: вместо выпадашки группа из трёх иконок-кнопок (SVG-полоски: слева/центр/справа, паттерн тумблеров B/I). **Шрифт** — одна строка: пикер (`ui/fontPicker.ts`) + тумблеры **B** (жирность 400↔700) и **I** (`style.italic`, курсив; дефолт `fontFamily: 'Arial'`). Пикер — не текстовый инпут: кнопка с именем текущего шрифта (набрана им самим) + выпадающий список шрифтов, **реально доступных в браузере** (проверка `document.fonts.check`), каждая строка набрана своим шрифтом с кириллической пробой «Аа Яя 123»; текущий шрифт всегда первым (даже кастомный), дженерики (sans-serif/serif/…) — всегда в конце. Чистая сборка списка `buildFontList(current, probe)` покрыта юнит-тестами. Выпадашка «Начертание» (400/600/700/900) удалена — жирность управляется только кнопкой B.

### Компактное цветовое поле (`colorAlphaField`)
Per-track цвета (заливка, обводка, свечение) используют компактный виджет в **одну строку**: label · swatch (клик открывает нативный picker для RGB) · слайдер прозрачности (alpha 0..1). Цвет хранится строкой (rgb hex или `rgba()`); alpha лежит в самой строке, виджет декомпозирует её на rgb+alpha и собирает обратно при изменении любого контрола. Так picker (не умеющий alpha) и слайдер alpha работают независимо.
- **Project-level** (общие): фон (тип: цвет/градиент/картинка/**видео**; выбор типа и цвета — здесь, загрузка файла картинки/MP4 — строкой «Фон» на таймлайне). При картинке/видео появляется селектор «Вписывание» (`bgFit`): «По центру, с обрезкой» (cover) / «Растянуть (деформация)» (stretch) / «Вместить целиком» (contain). Для «видео» карточка показывает имя файла и подсказку про цвет-фолбэк до/после видео. (Разрешение и FPS больше не редактируются здесь — см. ниже.)

## Компоненты

- **controls.ts** — верхняя панель: загрузка MP3, play/pause, запись таймингов (всегда в активную **текстовую** дорожку), единая кнопка «📂 Открыть» (авто-детект `.karaokeproject`/`.kfn` по расширению), экспорт. Кнопка «Запись таймингов» блокируется (становится серой), когда активная дорожка не текстовая; клик по ней в этом состоянии показывает попап «Выберите текстовую дорожку для записи таймингов». Состояние кнопки пересчитывается по подписке на store (при смене активной дорожки). Кнопка «Экспорт» открывает диалог (`exportDialog.ts`) с тремя вкладками — Видео (MP4) / Проект (.karaokeproject) / KaraFun (.kfn); для MP4 выбираются качество и FPS (см. `docs/export.md`). Сохранение проекта — это одна из вкладок экспорта (всё сохранение чего-либо = экспорт). **Каждая кнопка topbar** состоит из иконки (символ) + подписи в `<span class="topbar-btn-label">` (хелпер `setTopbarButton(btn, icon, label)` в `controls.ts`, используется и при создании, и в `refreshAll()`). На мобиле подписи скрыты (CSS `.topbar-btn-label { display:none }`), остаются только иконки; действие каждой кнопки дублируется в `title`. Заголовок «🎤 Karaoke Video Editor» сворачивается до иконки 🎤 на мобиле (CSS `.topbar-text { display:none }`).
- **lyricsEditor.ts** — переключатель дорожек (табы: имя + удалить активную, кнопка «+») над textarea. Textarea редактирует активную дорожку; `mergeTimings` применяется в её пределах.
- **preview.ts** — canvas 1920×1080 (масштабируется CSS), RAF-цикл вызывает `renderFrame`. При `bgType='video'` синхронизирует скрытый `<video>` (из `backgroundVideo.ts`) с аудио-часами (play/pause вместе, re-seek при рассинхроне >0.3с) и передаёт его в `renderFrame` как источник кадра фона.
- **stylePanel.ts** — панель (см. разделение выше). Контролы генерируются из деклараций полей и настроек рендерера.
- **timeline.ts** — canvas-таймлайн (см. `docs/timeline.md`).
- **exportDialog.ts** — модальный диалог экспорта (см. `docs/export.md`).
- **vocalBindDialog.ts** — диалог привязки текстовой дорожки к вокалу (⏱ на непривязанной): сообщение, плоские кнопки вокальных ролей, инлайн-ошибка при конфликте «один вокал — одна дорожка», Отмена/Esc/клик по фону.
- **propsSheet.ts** — модальное окно свойств дорожки с табами «Текст» / «Стиль» (только мобильный режим; см. «Адаптивность» ниже).

## Адаптивность / мобильный режим

Раскладка переключается по media query `max-width: 900px` (`main.ts` слушает `matchMedia`).

**Desktop (≥900px)**: 3 колонки (текст / превью / стиль) + таймлайн внизу — без изменений.

**Mobile (<900px)**: `#app` становится `grid-template-rows: auto minmax(42vh, 1fr) auto` — topbar / превью / таймлайн. Боковые колонки скрыты; превью закреплено сверху (минимум 42vh, поглощает остаток высоты), таймлайн **обнимает контент** (строка `auto`, как на десктопе; при `1fr` панель растягивалась до низа окна и под строкой «Фон» висела мёртвая пустота) и горизонтально скроллится. Текст и стиль — свойства дорожки, открываются в полноэкранном модальном окне `propsSheet.ts` через плавающую кнопку «✏️ Свойства» (FAB). Узлы `createLyricsEditor().root` и `createStylePanel().root` **перемещаются** между десктоп-колонками и панелями шита функцией `applyLayout(isMobile)` в `main.ts` (DOM-move сохраняет слушатели/state). Шит — единственный владелец размещения узлов: `applyLayout` монтирует их в `propsSheet.lyricsPanel`/`stylePanel` (мобильный) или в колонки (десктоп).

**Запись таймингов на мобильном**: тапом по overlay на превью (`.rec-overlay` в `preview.ts`), т.к. нет пробела. См. `docs/lyrics-and-timings.md`.

## Save/Load

Проект сериализуется в файл `.karaokeproject` (ZIP-контейнер: `project.json` + медиа, см. `docs/export.md`). Аудио, фоновая картинка и видео-фон хранятся как отдельные записи контейнера. При загрузке `setProject` клонирует проект.
