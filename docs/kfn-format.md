# Спецификация формата KaraFun (.kfn)

Полная спецификация бинарного контейнера KaraFun, собранная из:
- Серии статей по реверс-инжинирингу (George Yunaev / ulduzsoft.com, Part 1-4).
- Исходного кода парсера (github.com/gyunaev/spivak).
- Анализа реальных .kfn файлов трёх типов: простое караоке, с фоновой картинкой, с фоновым видео и бэк-вокалом.

## Обзор

.kfn — бинарный контейнер (архив) для хранения караоке: аудио, лирика с таймингами, фоновые изображения/видео. Данные хранятся «как есть», опционально зашифрованы AES-128-ECB.

Все числа — little-endian. Строки — UTF-8 с префиксом длины (Pascal-style).

## Структура файла

```
┌──────────────────────────┐
│ Заголовок (KFNB + блоки) │  начинается с магии "KFNB"
├──────────────────────────┤
│ Директория               │  кол-во файлов + записи
├──────────────────────────┤
│ Данные файлов            │  сырые байты (MP3, JPG, WMV, Song.ini)
└──────────────────────────┘
```

## 1. Заголовок

Начинается с 4 байт магии: `KFNB` (0x4B 0x46 0x4E 0x42).

Далее — последовательность **блоков** полей (ID3-style). Каждый блок:
- **4 байта**: имя поля (ASCII, напр. `TITL`, `ARTS`, `ENDH`).
- **1 байт**: тип данных:
  - `0x01` = integer: следующие 4 байта — little-endian uint32.
  - `0x02` = string: следующие 4 байта — длина строки (uint32), затем сама строка (UTF-8).
- **Данные**: 4 байта (integer) или 4+N байт (string).

Заголовок заканчивается блоком `ENDH`.

### Стандартные поля заголовка

| Поле | Тип | Описание |
|---|---|---|
| `DIFM` | int | Неизвестно (всегда 0 в образцах). |
| `DIFW` | int | Неизвестно (всегда 0 в образцах). |
| `GNRE` | int | ID жанра. `-1` (0xFFFFFFFF) = неизвестен. |
| `SFTV` | int | Версия ПО. В образцах: `0x01145A15` (18110997). |
| `MUSL` | int | Неизвестно (0 в образцах). |
| `ANME` | int | Неизвестно (13 в образцах). |
| `TYPE` | int | Тип файла (0 в образцах). |
| `FLID` | string(16) | AES-ключ шифрования (16 байт). Нули = без шифрования. |
| `TITL` | string | Название песни. |
| `ARTS` | string | Артист. |
| `SORC` | string | Исходный аудиофайл в формате `1,I,<имя.mp3>`. |
| `RGHT` | int | Авторские права (0 в образцах). |
| `PROV` | int | Провайдер (0 в образцах). |
| `IDUS` | string(16) | Идентификатор пользователя (16 пробелов в образцах). |
| `ENDH` | int | Маркер конца заголовка. Значение `-1` (0xFFFFFFFF). |

## 2. Директория

Идёт **сразу после** заголовка (после блока `ENDH`).

- **4 байта** (uint32): количество файлов в контейнере.
- Затем — **записи** для каждого файла.

### Формат записи директории

| Поле | Размер | Описание |
|---|---|---|
| Длина имени | 4 байта (uint32) | Длина имени файла в байтах. |
| Имя файла | N байт | Имя файла (UTF-8). |
| Тип файла | 4 байта (uint32) | 1=Song.ini, 2=аудио, 3=изображение, 4=шрифт, 5=видео. |
| Output Length | 4 байта (uint32) | Истинный размер файла (после расшифровки). |
| Offset | 4 байта (uint32) | Смещение данных **от конца директории**. |
| Input Length | 4 байта (uint32) | Размер в контейнере (для шифрованных = с padding до 16). |
| Flags | 4 байта (uint32) | `0` = без шифрования, `0x01` = AES-зашифровано. |

**Важно**: Offset — **относительный**, от конца директории (начала секции данных). Абсолютная позиция = `offset + dirEnd`.

Для незашифрованных файлов `Output Length === Input Length`.

## 3. Шифрование (опционально)

- **Алгоритм**: AES-128-ECB.
- **Ключ**: хранится в поле `FLID` заголовка (16 байт). Если FLID = нули → файлы не зашифрованы.
- **Что шифруется**: при «блокировке» проекта шифруется только `Song.ini` (медиа-файлы остаются открытыми).
- **Признак**: `flags & 0x01` в записи директории = файл зашифрован.
- **Padding**: зашифрованные данные добиваются до кратного 16 байтам. `Input Length` — с padding, `Output Length` — истинный размер (лишние байты отбрасываются после расшифровки).
- **IV**: нет (ECB mode).
- **Слабость**: ECB — одинаковые блоки дают одинаковый шифротекст.

## 4. Song.ini — лирика и тайминги

Текстовый INI-файл (UTF-8, CRLF). Содержит метаданные песни, эффекты (включая лирику с таймингами), фоновые изображения/видео.

### Секции

#### `[General]` — метаданные

| Поле | Описание |
|---|---|
| `Title` | Название песни. |
| `Artist` | Артист. |
| `Album`, `Composer`, `Year`, `Track` | Прочие метаданные (часто пустые). |
| `GenreID` | ID жанра (-1 = неизвестен). |
| `Copyright`, `Comment` | Прочее. |
| `Source` | Исходный аудиофайл: `1,I,<имя.mp3>`. |
| `EffectCount` | Количество эффектов (секций `[EffN]`). |
| `LanguageID` | Язык (часто пустой). |
| `DiffMen`, `DiffWomen` | Сложность (0). |
| `KFNType` | Тип (0). |
| `Properties` | Свойства (24). |
| `KaraokeVersion`, `VocalGuide`, `KaraFunization` | Доп. поля (часто пустые). |
| `InfoScreenBmp` | Картинка инфо-экрана. |
| `GlobalShift` | Глобальный сдвиг таймингов (0 = без сдвига). |

#### `[Marks]` — закладки навигации

`Mark0`..`Mark8` — значения `-1` (пустые закладки). Используются для навигации по песни.

#### `[MP3Music]` — дополнительные аудиотреки

| Поле | Описание |
|---|---|
| `NumTracks` | Количество доп. треков (0 = только основной). |
| `Track0` | Доп. трек: `<имя.mp3>,<тип>,<смещение>,<>,<>`. Тип `2` = бэк-вокал. |

#### `[EffN]` — эффекты

Каждый эффект — отдельная секция. `EffectCount` задаёт их количество. Эффекты нумеруются с 1 (`[Eff1]`, `[Eff2]`, ...).

**ID эффекта** определяет тип:

| ID | Тип | Описание |
|---|---|---|
| 1 | Текст с таймингами | Основная лирика. Содержит `Text0..N`, `Sync0..N`, шрифты, цвета. |
| 2 | Текст с таймингами | Альтернативная лирика (тот же формат, что ID=1). |
| 51 | Фоновое изображение | Картинка (ссылка через `LibImage`). |
| 62 | Фоновое видео | Видео (ссылка через `VideoFile`). |

##### Эффект лирики (ID=1 или 2)

| Поле | Описание |
|---|---|
| `ID` | 1 или 2. |
| `InPractice` | Показывать в режиме тренировки (`-1` = да, `0` = нет). |
| `Enabled` | Включён (`-1` = да). |
| `Locked` | Заблокирован (0). |
| `Sync0`..`SyncN` | Тайминги слогов для строки N, в **сантисекундах** (мс/10), comma-separated. `-1` = неразмеченный. |
| `Text0`..`TextN` | Текст строки N. Слоги разделяются `/` (внутри слова) и пробелами (между словами). Пустое значение = пустая строка (пауза). |
| `TextCount` | Количество текстовых строк. |
| `Font` | Шрифт в формате `<имя>*<размер>`, напр. `Arial*18`. |
| `ActiveColor` | Цвет активного (закрашиваемого) текста. ARGB: `#AARRGGBB`. |
| `InactiveColor` | Цвет неактивного текста. |
| `FrameColor` | Цвет обводки. |
| `InactiveFrameColor` | Цвет обводки неактивного. |
| `FrameType` | Тип рамки (`Frame2` в образцах). |
| `Alignment` | Выравнивание (`Center`). |
| `Trajectory` | Анимация появления: `<тип>*<парам1>*<...>`, напр. `PlainBottomToTop*1.0*1.0*1.0*1.0`. |
| `SelTextEffect` | Эффект выделения: `NoEffect*1.0*1.0*1.0*1.0`. |
| `IsFill` | Заливка текста (`1` = да). |
| `IsFade` | Затухание по краям (`1` = да). |
| `Preview` | Превью (0). |
| `Fixed` | Фиксированная позиция (0). |
| `LineCount` | Количество одновременно видимых строк (для скролла). |
| `AspectRatio` | Соотношение сторон (1). |
| `OffsetX`, `OffsetY`, `OffsetZ` | Смещение текста (пиксели). |
| `InSync` | Синхронизирован с музыкой (1). |
| `NbAnim` | Количество анимаций (0). |

##### Эффект изображения (ID=51)

| Поле | Описание |
|---|---|
| `LibImage` | Имя файла картинки (из директории контейнера, type=3). |
| `ImageColor` | Цветовой фильтр (`#FFFFFFFF` = без фильтра). |
| `AlphaBlending` | Режим смешивания (`Opacity`). |
| `Color` | Цвет (`#000000`). |
| `OffsetX`, `OffsetY` | Смещение. |
| `Depth` | Z-глубина (порядок слоёв). |

##### Эффект видео (ID=62)

| Поле | Описание |
|---|---|
| `VideoFile` | Имя файла видео (из директории контейнера, type=5). |
| `PlayAtStart` | Воспроизвести с начала (`1`). |
| `SeekTime` | Точка старта (0). |
| `LoopVideo` | Зациклить (`0` или `1`). |
| `DisplayLastFrame` | Показывать последний кадр после окончания (`0`). |
| `ZoomScale` | Масштаб (100 = 100%). |
| `Filter` | Цветовой фильтр (`#FFFFFFFF`). |
| `AlphaBlending` | Режим смешивания (`Opacity`). |
| `OffsetX`, `OffsetY` | Смещение. |

### Формат таймингов

Тайминги в `Sync{n}` — **сантисекунды** (1/100 секунды). Для перевода в миллисекунды: `ms = value * 10`.

**Важно**: Sync НЕ соответствует Text по индексу строки. `Sync0..SyncN` — это **порции** (~41 значение каждая) единого плоского массива таймингов для **всех слогов песни** в порядке чтения. Все значения из `Sync0`, затем `Sync1`, и т.д. назначаются слогам по порядку — слог 0 получает Sync-значение 0, слог 1 — значение 1, и т.д., независимо от того, в какой строке текста находится слог.

Слоги извлекаются из `Text0..TextN` разбиением по `/` и пробелам. Пустые строки (`Text6=`) не содержат слогов и не потребляют Sync-значения.

Пример: песня с 338 слогами в 57 текстовых строках имеет 9 Sync-строк (по ~40 значений), всего 338 значений.

### Формат цветов

Цвета в формате **ARGB**: `#AARRGGBB` (Alpha, Red, Green, Blue — каждый 2 hex-цифры). Напр. `#00ACFFFF` = полупрозрачный голубой (Alpha=0x00, R=0xAC, G=0xFF, B=0xFF).

### Формат шрифта

`Font=<семейство>*<размер>`, напр. `Arial*18`. Разделитель — звёздочка `*`.

## 5. Типы файлов в контейнере

| Type | Расширение | Описание |
|---|---|---|
| 1 | .ini | Song.ini — лирика с таймингами. |
| 2 | .mp3, .ogg, .wav | Аудио (основной трек + доп. треки). |
| 3 | .jpg, .png, .bmp | Фоновое изображение. |
| 4 | .ttf, .otf | Шрифт. |
| 5 | .wmv, .avi, .mpg | Фоновое видео. |
