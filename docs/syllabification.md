# Автоматическое слогоделение

## Обзор

Модуль разбивает слова в тексте песни на слоги, расставляя `/` прямо в тексте. Пользователь нажимает кнопку «✂ Разбить на слоги», язык определяется автоматически, и слова получают слэши внутри: «Привет» → «При/вет». После этого текст можно редактировать вручную.

## Архитектура (`src/lib/syllabification/`)

Модульная система — по файлу на язык + общий интерфейс + реестр (аналогично рендерерам текста).

| Файл | Назначение |
|---|---|
| `types.ts` | Интерфейс `Syllabifier`, функция `detectLanguage` |
| `registry.ts` | `SYLLABIFIERS` — реестр, `getSyllabifier(lang)` |
| `russian.ts` | Слогоделение для русского |
| `english.ts` | Для английского |
| `german.ts` | Для немецкого |
| `index.ts` | Главная функция `syllabifyText(text)` |

### Интерфейс `Syllabifier`

```ts
interface Syllabifier {
  lang: string;           // 'ru' | 'en' | 'de'
  label: string;          // для UI
  syllabify(word: string): string[];  // "Привет" → ["При", "вет"]
}
```

### Как добавить язык

1. Создать модуль `src/lib/syllabification/<lang>.ts`, реализующий `Syllabifier`.
2. Зарегистрировать в `registry.ts` (`SYLLABIFIERS[lang] = ...`).
3. Добавить детект в `detectLanguage` (`types.ts`).
4. Всё — `syllabifyText` и UI подхватят автоматически.

## Детект языка (`detectLanguage`)

Эвристика по символам:
- Кириллица ≥ латиницы → `'ru'`.
- Немецкие символы (ä, ö, ü, ß) > 5% латиницы → `'de'`.
- Иначе латиница → `'en'`.
- Пустой текст → `null`.

## Главная функция (`syllabifyText`)

1. `detectLanguage(text)` → lang.
2. Если язык не поддерживается — вернуть текст без изменений.
3. Разбить текст на токены (слова + разделители сохраняются).
4. Каждое слово → `syllabifier.syllabify(word)`.
5. Собрать обратно: слоги внутри слова через `/`, слова через пробелы.
6. Пунктуация и регистр сохраняются.

## Правила по языкам

### Русский (`russian.ts`)

Основа: «один гласный — один слог».

Гласные: а, о, у, ы, и, э, е, ё, ю, я.
Сонорные: й, р, л, м, н.

Правила для согласных между гласными:
- Один согласный → к следующему слогу (от/крыл).
- Кластер: сонорные в начале остаются с предыдущим (солн/це — «лн» с 'о', «ц» к 'е').
- Сонорант + шумный: весь кластер к следующему (по/лка — «лк» к 'а').
- Удвоенные согласные делятся (длин/ный — «нн» делится).
- Два шумных: первый остаётся, второй уходит (бук/ва).

### Английский (`english.ts`)

Гласные: a, e, i, o, u, y.

Правила:
- VCV → делить перед согласным (pa/per).
- VCCV → делить между согласными (bas/ket).
- Digraphs (th, sh, ch, ph, wh, ck) — неделимые, целиком к следующему.
- Silent 'e' на конце не образует слог (make → 1 слог).
- Doubled consonants делятся (rab/bit).
- Consonant + 'le' на конце — отдельный слог (ap/ple, tab/le).

**Compound-префиксы**: слова, начинающиеся на `every`, `some`, `any`, — разбиваются: префикс отрезается и делится по своему правилу, а остаток прогоняется через обычный syllabifier. Так `everybody` → `eve/ry` + `bo/dy` = `eve/ry/bo/dy` автоматически.

**Словарь исключений**: отдельные слова, которые правила не могут правильно разделить (every, beautiful, other, mother, water, about, alone...). Расширяется по мере обнаружения.

### Немецкий (`german.ts`)

Гласные: a, e, i, o, u, ä, ö, ü, y.
Дифтонги: ei, eu, äu, au, ie.

Правила:
- VCV → делить перед согласным (le/sen).
- VCCV → делить между согласными (Fin/ger).
- Неделимые кластеры: sch, ch, ph, ck, tz, pf — целиком к следующему.
- Слова ≤3 букв → один слог.

## UI

Кнопка **«✂ Разбить на слоги»** в редакторе текста (`lyricsEditor.ts`). По клику:
1. `syllabifyText(ta.value)` — детект языка + разбиение.
2. Результат записывается в textarea со слэшами.
3. Триггерится `input`-событие → `mergeTimings` сохраняет существующие тайминги.
4. Кнопка показывает язык: «✂ Разбито (Русский)».

## Тесты (`scripts/test-syllabify.mjs`)

Для каждого языка — набор слов с ожидаемым разбиением:
- Детект языка (ru/en/de/пусто).
- Compound words (everybody → eve/ry/bo/dy).
- Пунктуация и регистр сохраняются.
- Многострочность.

## Ограничения

Английское слогоделение нерегулярно — правила покрывают большинство слов, но не все. Словарь исключений расширяется по мере обнаружения проблемных слов. Пользователь всегда может поправить слэши вручную после автоматического разбиения.
