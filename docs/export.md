# Экспорт

Поддерживаются два формата: **MP4** (видео с закрашиваемым текстом) и **KFN** (контейнер KaraFun с лирикой + таймингами + аудио).

## Экспорт MP4

Полностью в браузере, без сервера и ffmpeg. WebCodecs кодирует кадры (H.264) и аудио (AAC), Mediabunny мьюксит их в один MP4.

### Качество

Пресеты от 360p до 4K (`QUALITY_PRESETS` в `src/lib/export.ts`), дефолт 480p. Каждый пресет задаёт высоту и битрейт. Ширина выводится из соотношения сторон проекта, выравнивается до чётного числа.

## Рендер

Кадр рендерится той же `renderFrame` (WYSIWYG). Проект масштабируется под целевое разрешение через `scaledProject` (умножаются `fontSize`, `strokeWidth`, `glowBlur`). Рендер идёт прямо в целевой canvas — без двойного прохода.

## Аудио

Декодированный `AudioBuffer` целиком подаётся в `AudioBufferSource` Mediabunny — кодируется в AAC.

## Прогресс и отмена

- Прогресс: `(currentFrame / totalFrames)` → коллбэк → модальный диалог.
- Отмена: `AbortSignal` + проверка в каждой итерации цикла. При отмене вызывается `output.cancel()` для освобождения энкодера.
- `ExportCanceledError` — отдельный класс для отмены (отличается от ошибок).

## Модальный диалог (`src/ui/exportDialog.ts`)

Два состояния: выбор качества → рендеринг с прогресс-баром. Закрытие (X / клик по фону / Esc / «Отмена») в любом состоянии отменяет экспорт.

## Требования

Chrome/Edge (WebCodecs API). Feature-detect через `canExport()`.

## Важно

- `quality` в encoding-конфиге Mediabunny должен быть **инстансом `Quality`**, не строкой (`new Quality('high')` или `new Quality({ bitrate })`).
- `frameRate` указывается в метаданных трека (`addVideoTrack(source, { frameRate })`), не в encoding-конфиге.

## Экспорт KFN (KaraFun)

Модули: `src/lib/kfnExport.ts` (экспорт), `src/lib/kfnImport.ts` (импорт).

Формат `.kfn` — бинарный контейнер KaraFun:
- **Заголовок**: магия `KFNB` + ID3-style блоки (`TITL`, `ARTS`, `SORC`, `ENDH` и др.).
- **Директория**: кол-во файлов + записи (имя, тип, размер, смещение, флаги). Типы: 1=Song.ini, 2=аудио, 3=картинка.
- **Данные файлов**: сырые байты (MP3 как есть, Song.ini как UTF-8 текст).

### Song.ini

Текстовый INI-файл с лирикой и таймингами:
- `Text{n}=...` — строки лирики, слоги через `/` и пробелы.
- `Sync{n}=...` — тайминги в **сантисекундах** (мс / 10), comma-separated, по значению на слог.
- `TextCount=N` — количество строк.
- Секции: `[General]`, `[Marks]`, `[MP3Music]`, `[Eff1]`.

### Конвертация

При экспорте: `Syllable.startMs` → `startMs / 10` (сантисекунды), текст собирается с разделителями из `sep` (`' '`→пробел, `'/'`→слэш).

При импорте: обратное преобразование, сантисекунды → мс. Аудио извлекается как `Uint8Array` и загружается через `audioEngine.loadBytes()`.

### AudioEngine.loadBytes

Загрузка аудио из raw-байтов (для KFN импорта). Создаёт Blob из байтов, декодирует в AudioBuffer.

### Тесты

`scripts/test-kfn.mjs` — полный round-trip: экспорт синтетического проекта → парсинг → проверка структуры (KFNB, директория, Song.ini) → импорт → проверка таймингов слогов.
