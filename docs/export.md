# Экспорт

Поддерживаются три формата: **MP4** (видео с закрашиваемым текстом), **KFN** (контейнер KaraFun с лирикой + таймингами + аудио) и **собственный файл проекта** `.karaokeproject`.

## Файл проекта (`.karaokeproject`)

Модуль: `src/lib/projectFile.ts`.

Собственный формат — ZIP-контейнер (store, без сжатия — MP3/JPG уже сжаты) с расширением `.karaokeproject`. Открывается любым архиватором; спроектирован как «бандл документа» для будущего десктоп-приложения. Структура:

```
project.karaokeproject (ZIP)
├── project.json     — метаданные проекта (БЕЗ встроенных медиа-байтов)
├── audio.<ext>      — сырые байты аудио (если есть)
└── background.<ext> — сырые байты фоновой картинки (если фон — картинка)
```

- **`saveProject(project, audioBytes)`** → `{ blob, filename }`: метаданные сериализуются в `project.json`, аудио и фон — отдельные записи. Тяжёлый dataURL фона выносится из JSON в запись контейнера (в JSON остаётся только имя записи как маркер).
- **`loadProject(data)`** → `{ project, audioBytes, audioFileName }`: парсит ZIP, восстанавливает dataURL фона из записи. Аудио возвращается сырыми байтами для `audioEngine.loadBytes()`.
- Старый формат (голый `.json`) **не поддерживается** — только `.karaokeproject`.
- Зависимость: `fflate` (~8KB, чистый JS, без нативных модулей).

### Тесты

`scripts/test-project.mjs` — round-trip: сохранение → загрузка → проверка (ZIP-сигнатура, аудио-байты, фон-картинка, дорожки/настройки, кейсы без аудио/без фона).

## Экспорт MP4

Полностью в браузере, без сервера и ffmpeg. WebCodecs кодирует кадры (H.264) и аудио (AAC), Mediabunny мьюксит их в один MP4.

### Качество

Пресеты от 360p до 4K (`QUALITY_PRESETS` в `src/lib/export.ts`), дефолт 480p. Каждый пресет задаёт высоту и битрейт. Ширина выводится из соотношения сторон проекта, выравнивается до чётного числа.

## Рендер

Кадр рендерится той же `renderFrame` (WYSIWYG), которая рисует общий фон и в цикле все дорожки. Проект масштабируется под целевое разрешение через `scaledProject`: пиксельные значения стиля (`fontSize`, `strokeWidth`, `glowBlur`) умножаются на коэффициент для **каждой** дорожки отдельно. Рендер идёт прямо в целевой canvas — без двойного прохода.

## Аудио

Декодированный `AudioBuffer` целиком подаётся в `AudioBufferSource` Mediabunny — кодируется в AAC.

## Прогресс и отмена

- Прогресс: `(currentFrame / totalFrames)` → коллбэк → модальный диалог.
- Отмена: `AbortSignal` + проверка в каждой итерации цикла. При отмене вызывается `output.cancel()` для освобождения энкодера.
- `ExportCanceledError` — отдельный класс для отмены (отличается от ошибок).

## Модальный диалог (`src/ui/exportDialog.ts`)

Единая точка экспорта: одна кнопка «Экспорт» открывает попап с **табами** форматов — **Видео (MP4)** и **KaraFun (.kfn)**.

- **Таб Видео**: селектор качества (360p…4K, дефолт 480p) + подсказка про размер/время.
- **Таб KaraFun**: предупреждения о совместимости (`collectKfnWarnings`, см. ниже), если в проекте есть несовместимые настройки; иначе сообщение, что всё совместимо.

Кнопки: «Отмена» + «Экспорт». После старта диалог блокируется и показывает прогресс-бар для обоих форматов; «Отмена» → «Отменить». Закрытие (X / клик по фону / Esc / «Отмена») в любом состоянии отменяет экспорт.

`openExportDialog(kfnWarnings)` возвращает `{ promise, setProgress, close, cancel }`. `promise` резолвится с `{ format: 'mp4' | 'kfn', qualityId }`; владелец запускает соответствующий экспорт и сообщает прогресс через `setProgress`.

### Прогресс для KFN

`exportToKfn` — **асинхронная** с `onProgress` и `signal` (как MP4). Фазы: подготовка Song.ini (0–10%) → декодирование фона (10–35%) → сборка контейнера с копированием аудио (35–90%) → финальная сборка + Blob (90–100%). Между фазами — `setTimeout(0)` yield, чтобы UI отрисовался.

### Предупреждения KaraFun (`collectKfnWarnings`)

`collectKfnWarnings(project)` проверяет совместимость **без построения файла** (для предпросмотра в табе): >2 дорожек (лимит KaraFun), нераспознанный рендерер (≠ scroller/classic → кастится к scroller), толщина обводки >5 (clamp до Frame5). Те же условия перепроверяются при экспорте.

## Требования

MP4: Chrome/Edge (WebCodecs API). Feature-detect через `canExport()`. Если недоступен — видео-таб недоступен, но KaraFun-экспорт работает всегда.

## Важно

- `quality` в encoding-конфиге Mediabunny должен быть **инстансом `Quality`**, не строкой (`new Quality('high')` или `new Quality({ bitrate })`).
- `frameRate` указывается в метаданных трека (`addVideoTrack(source, { frameRate })`), не в encoding-конфиге.

## Экспорт KFN (KaraFun)

Модули: `src/lib/kfnExport.ts` (экспорт), `src/lib/kfnImport.ts` (импорт).

Формат `.kfn` — бинарный контейнер KaraFun:
- **Заголовок**: магия `KFNB` + ID3-style блоки (`TITL`, `ARTS`, `SORC`, `ENDH` и др.).
- **Директория**: кол-во файлов + записи (имя, тип, размер, смещение, флаги). Типы: 1=Song.ini, 2=аудио, 3=картинка.
- **Данные файлов**: сырые байты (MP3 как есть, Song.ini как UTF-8 текст, картинка как есть).

### Song.ini

Текстовый INI-файл с лирикой и таймингами:
- `Text{n}=...` — строки лирики, слоги через `/` и пробелы.
- `Sync{n}=...` — тайминги в **сантисекундах** (мс / 10), comma-separated, по значению на слог (локально для каждого эффекта).
- `TextCount=N` — количество строк.
- Секции: `[General]`, `[Marks]`, `[MP3Music]`, по одной `[EffN]` на дорожку + опционально `[Eff1]` с `ID=51` для фона.

### Мульти-дорожечность

KFN поддерживает **до двух текстовых эффектов** (ID=1 основная, ID=2 альтернативная). Каждая дорожка проекта → отдельная секция `[EffN]`. Подробнее о маппинге полей — см. `docs/kfn-format.md`.

### Фоновая картинка

При `bgType='image'` фон декодируется из `bgImageDataUrl` → сырые байты → запись контейнера (type=3) + секция `[Eff]` с `ID=51` и `LibImage=background.<ext>`. При импорте — обратное преобразование.

### AudioEngine.loadBytes

Загрузка аудио из raw-байтов (для KFN импорта). Создаёт Blob из байтов, декодирует в AudioBuffer.

### Тесты

`scripts/test-kfn.mjs` — полный round-trip: экспорт синтетического проекта → парсинг → проверка структуры (KFNB, директория, Song.ini) → импорт → проверка таймингов слогов, цветов, фона.
