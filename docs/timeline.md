# Таймлайн

## Раскладка

Таймлайн построен как аудиоредактор: **фиксированный левый gutter** (шапки) + **горизонтально-скроллируемый canvas** справа. Gutter не скроллится, canvas — да.

- **Левый gutter** (`GUTTER_W`, HTML, не canvas): вертикальный стек шапок. Сверху — spacer под линейку, затем опциональная шапка waveform с текстом «минус», затем по шапке на каждую дорожку. Все шапки одинаковой ширины; высоты синхронизированы со строками canvas (те же константы: `RULER_H`, `WAVE_H`, `ROW_H`, `TOP_PAD`, `TRACK_PAD`). Клик по шапке дорожки → активация (`activeTrackId`). Шапки перестраиваются только при смене набора дорожек / имён / активной дорожки / видимости waveform (по сигнатуре), не на каждый кадр.
- **Canvas** (таймлайн): время отсчитывается **от левого края canvas (x=0)**. Сверху вниз:
  1. **Общая линейка времени** (ruler).
  2. **Один waveform** (опционально).
  3. **Полоса маркеров на каждую дорожку** — ровно одна строка (`ROW_H`) на дорожку.

Высота canvas растёт с числом дорожек: `RULER_H + TOP_PAD + waveBlock + tracks.length * (ROW_H + TRACK_PAD)`.

## Полоса дорожки

Каждая дорожка рисуется на своей горизонтальной строке canvas. Активная дорожка подсвечена тонкой полупрозрачной полосой фона (имя дорожки — в шапке gutter, не на canvas).

**Неразмеченные слоги не рисуются** (инвариант — см. `docs/architecture.md`).

Каждый размеченный слог рисуется как тонкая вертикальная линия (1px) с текстовой меткой и полосой длительности (градиент до следующего слога **в той же дорожке**). Зона захвата мышью шире линии (`HIT_W = 8px` в каждую сторону).

## Маркеры и взаимодействие

- **Клик по шапке дорожки** в gutter — делает дорожку активной (`activeTrackId`).
- **Drag маркера** на canvas — меняет `startMs` слога в соответствующей дорожке.
- **Клик по пустому месту** на canvas — перемотка (seek).
- **Shift+колесо** — зум (с привязкой к курсору).
- **Обычное колесо** — горизонтальная прокрутка.

## Ограничение перетаскивания

При drag слог нельзя перетащить **раньше предыдущего** и **позже следующего** размеченного слога **в пределах той же дорожки**. Границы вычисляются по плоскому массиву слогов перетаскиваемой дорожки: ищется ближайший размеченный слог слева и справа от текущего.

## Waveform

Опциональная дорожка (настройка `project.showWaveform`), рисуется между ruler и строками дорожек — одна на весь таймлайн. Пики вычисляются из `AudioBuffer` через `src/lib/waveform.ts`, кешируются в `WeakMap` по (buffer × buckets). В gutter ей соответствует шапка с текстом «минус».

## Playhead

Красная вертикальная линия (2px), позиция = текущее время воспроизведения. При записи — «таблетка» с текстом следующего слога справа от плейхеда (в области активной дорожки).

## Запись таймингов

Запись всегда идёт для **активной дорожки**. В режиме записи рядом с плейхедом показывается следующий слог активной дорожки для отснимания. Нажатие Space (через `timing.ts`) присваивает `startMs` слогу активной дорожки.
