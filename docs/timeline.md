# Таймлайн

## Раскладка

Таймлайн — горизонтальный canvas в горизонтально-скроллируемом контейнере. Фиксированная высота: ruler + waveform (опционально) + **3 строки** слогов.

Слоги распределяются по 3 строкам **циклически** по глобальному плоскому индексу: слог 0 → строка 0, слог 1 → строка 1, слог 2 → строка 2, слог 3 → строка 0 и т.д. Это фиксирует высоту независимо от количества текста.

Высота строки (`ROW_H`) = высота текста (~18px), не фиксированная большая.

## Маркеры

Каждый размеченный слог рисуется как тонкая вертикальная линия (1px) с текстовой меткой и полосой длительности (градиент до следующего слога). Зона захвата мышью шире линии (`HIT_W = 8px` в каждую сторону).

**Неразмеченные слоги не рисуются** (инвариант — см. `docs/architecture.md`).

## Взаимодействие

- **Drag маркера** — меняет `startMs` слога.
- **Клик по пустому месту** — перемотка (seek).
- **Shift+колесо** — зум (с привязкой к курсору).
- **Обычное колесо** — горизонтальная прокрутка.

## Ограничение перетаскивания

При drag слог нельзя перетащить **раньше предыдущего** и **позже следующего** размеченного слога. Границы вычисляются по плоскому массиву: ищется ближайший размеченный слог слева и справа от текущего.

## Waveform

Опциональная дорожка (настройка `project.showWaveform`), рисуется между ruler и строками. Пики вычисляются из `AudioBuffer` через `src/lib/waveform.ts`, кешируются в `WeakMap` по (buffer × buckets).

## Playhead

Красная вертикальная линия (2px), позиция = текущее время воспроизведения. При записи — «таблетка» с текстом следующего слога справа от плейхеда.

## Запись таймингов

В режиме записи рядом с плейхедом показывается следующий слог для отснимания. Нажатие Space (через `timing.ts`) присваивает `startMs`.
