# Система рендереров текста

## Интерфейс

Каждый режим анимации текста — независимый модуль, реализующий общий интерфейс `TextRenderer` (`src/lib/text_renderers/types.ts`):

- `id: Layout` — идентификатор режима (`'scroller'`).
- `label: string` — название для UI.
- `settings: RenderSettingSpec[]` — декларация настроек режима (для автогенерации контролов в UI).
- `render(ctx, timeMs, env, settings)` — отрисовать текстовый слой одной дорожки одного кадра. Фон уже нарисован оркестратором.

`RenderEnv` описывает **одну дорожку** (не весь проект):
- `lines` — строки этой дорожки.
- `style` — `TextStyle` этой дорожки.
- `width`, `height` — размеры canvas (общие).
- `durationMs` — длительность песни (для конца последнего слога).
- `timings` — предвычисленный массив `TimedSyllable` этой дорожки.
- `activeLineIndex` — индекс активной строки этой дорожки.

## Оркестратор

`src/lib/render.ts` — тонкий слой:
1. Рисует общий фон один раз (`drawBackground`: цвет / градиент / картинка), по `project.background`.
2. **Цикл по `project.tracks`**: для каждой дорожки — `buildTimings(track.lines, project.durationMs)`, `activeIndex`, `applyFont(track.style)`, выбор рендерера по `track.style.layout`, мёрдж настроек, `renderer.render(...)`.
3. Дорожки рисуются в порядке массива и **могут перекрываться**.

Сигнатура `renderFrame(ctx, timeMs, project)` не меняется — потребители (preview, export) не знают о дорожках.

## Реестр

`src/lib/text_renderers/registry.ts`:
- `TEXT_RENDERERS: Record<Layout, TextRenderer>` — все рендереры по id.
- `RENDERER_LIST` — список для UI-селектора.
- `getRenderer(layout)` — выбор с фолбэком на `'scroller'`.
- `allDefaultSettings()` — дефолтные настройки всех рендереров.

## Как добавить новый режим

1. Создать модуль `src/lib/text_renderers/<name>.ts`, реализующий `TextRenderer`.
2. Добавить id в тип `Layout` (`src/types.ts`).
3. Зарегистрировать в `registry.ts` (`TEXT_RENDERERS` и `RENDERER_LIST`).
4. Добавить дефолтные настройки в `createTextTrack` (`src/types.ts`).
5. Оркестратор и UI подхватят автоматически.

## Общие хелперы (`helpers.ts`)

Layout-агностичные функции, используемые всеми рендерерами:

- `buildTimings(lines, durationMs)` → `TimedSyllable[]` — **только размеченные слоги** (инвариант: неразмеченные исключаются). Принимает `lines` дорожки и `durationMs` проекта (не весь `Project`).
- `progress(ts, timeMs)` — степень заливки 0..1.
- `activeIndex(timings, timeMs)` — индекс активного слога.
- `layoutLine(ctx, timings, lineIndex, timeMs, activeLineIndex, style)` — раскладка слогов строки: позиции X, ширины, fill progress. Пробел между словами рисуется реальным пробелом (через `sep === ' '`), слэш — без отступа.
- `drawSyllable(ctx, ls, originX, cx, style)` — отрисовка одного слога: базовый цвет (`colorBase`) → clipped highlight заливка (`colorHighlight`) → stroke (обводка: `strokeColorActive` для закрашенного/активного слога, иначе `strokeColorInactive`) → glow → active-анимация. Состояние обводки симметрично заливке — спетый слог рисуется активной обводкой, неспетый неактивной (маппится на KFN `FrameColor`/`InactiveFrameColor`).
- `lineOriginX(style, lineWidth, canvasWidth)` — X-позиция строки по выравниванию.
- `applyFont(ctx, style)` — установка шрифта.

Все хелперы принимают `TextStyle` (стиль дорожки), а не весь `Style`.

## Настройки

Каждый рендерер декларирует свои настройки в `settings: RenderSettingSpec[]`. Значения хранятся в `track.rendererSettings[rendererId][key]` (на уровне дорожки). UI (`stylePanel.ts`) автогенерирует контролы (числовые → слайдер, boolean → чекбокс) для активной дорожки.

## Текущие режимы

### `scroller` — «Бегущая (вылет снизу)»
Кинотитры: активная строка в вертикальном центре, текст едет снизу вверх с постоянной скоростью. Скорость `v = (height/2) / previewMs`, где `previewMs = previewSec × 1000` — за столько миллисекунд до начала строка входит снизу экрана (настройка `previewSec`, дефолт 10). Таким образом, на нижней половине видны строки, которые начнутся в течение `previewSec` секунд. Скорость едина для всей песни (в пределах дорожки); расстояние между строками отражает их временные gap'ы (плотные — ближе, паузы — дальше).

`previewSec` принимает только фиксированные значения из набора KaraFun Studio (`SCROLLER_PREVIEW_SEC_VALUES`: 0.62, 0.74, 0.88, 1.1, …, 40), в UI это dropdown. Маппится на KaraFun `Trajectory=PlainBottomToTop*<param>*…` по формуле **`param = 10 / previewSec`** (обратная пропорция): param 1.0 → 10 с, param 0.42 → 24 с, param 11.31 → 0.88 с. При импорте `previewSec = 10 / param` с квантованием к ближайшему значению из набора.

### `classic` — «Классическое караоке»
Текст **неподвижен**. На экране N фиксированных слотов (мест под строки), центрированных по вертикали. Слот строки = `lineIndex mod N` → вывод **закольцован**: 5-я строка рисуется на месте 1-й.

Жизненный цикл каждой строки (по alpha):
- **Появление**: за `fadeMs` до начала строки alpha плавно растёт 0 → 1.
- **Пение** (от первого до последнего timed-слога строки): alpha = 1, активные слоги закрашиваются (highlight через общий `drawSyllable`).
- **После конца**: alpha плавно падает 1 → 0 за `fadeMs` (строка тускнеет и исчезает). К моменту, когда слот понадобится новой строке (через N строк), она уже невидима.

Активная строка — самая яркая; будущие (fade-in) и прошлые (fade-out) тусклее, фокусируя взгляд на текущей. Закраска слогов, обводка и свечение — через общий `drawSyllable`, идентично scroller; отличается только позиционирование.

Настройки: `lineSlots` (слотов/строк видно, 2..16, дефолт 4), `fadeMs` (длительность появления и исчезновения, 0..6000, дефолт 1500; 0 = мгновенно), `offsetX`/`offsetY` (смещение всего блока слотов в пикселях, может быть отрицательным, дефолт 0). Смещение применяется через `ctx.translate` к блоку целиком — двигает центр окна вместе со всеми слотами; `fadeMs` и `lineSlots` сохраняются при KFN-импорте/экспорте.

Границы строки для alpha считаются по её timed-слогам: `start = min(startMs)`, `end = max(endMs)`. Строки без timed-слогов пропускаются (инвариант: неразмеченные слоги не рендерятся).
