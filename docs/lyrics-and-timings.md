# Текст и тайминги

## Парсер (`src/lib/textParser.ts`)

Разбиение текста на слоги:
- **Разделители**: пробел (и таб), `/`, перенос строки.
- **Всё остальное** (буквы, цифры, пунктуация `. , ! ?`) остаётся частью слога.
- Несколько разделителей подряд схлопываются (нет пустых слогов).

Каждый слог хранит `sep` — разделитель, который шёл перед ним (`' '` для пробела, `'/'` для слэша, `''` для первого в строке). Это даёт точный round-trip: `serializeLyrics` восстанавливает оригинальный текст (пробелы остаются пробелами, слэши — слэшами).

## Модель данных

```ts
Syllable { text: string; startMs: number | null; sep?: string }
Line { syllables: Syllable[] }
```

`startMs` — момент начала заливки слога. `null` = неразмещённый. Конец слога определяется в `buildTimings`:
- середина строки: конец = старт следующего слога (в той же строке);
- **последний слог строки**: конец = `startMs + 500мс` (фиксированная короткая заливка, чтобы слог не тянулся медленно через паузу до следующей строки);
- последний слог песни: конец = длительность песни (заливается полностью).

Таймлайн рисует полосу длительности градиентом до следующего слога в той же дорожке (визуально), но фактическая заливка в кадре идёт по `buildTimings`.

## Перенос таймингов при редактировании (`mergeTimings`)

**Чисто позиционный перенос по глобальному плоскому индексу, в пределах активной дорожки.**

При каждом изменении текста в редакторе (который всегда редактирует активную дорожку):
1. Текст парсится заново → `newLines`.
2. `mergeTimings(track.lines, newLines)` переносит тайминги.
3. Все слоги (старые и новые) объединяются в плоский массив.
4. Слог `i` в новом массиве получает тайминг слога `i` в старом массиве.
5. Если новых слогов больше (разбиение) — последний становится `null`.

Пример: `[а(100), б(200), в(300)]` → разбили «а» → `[а1, а2, б, в]`:
`а1←100, а2←200, б←300, в→null`.

**Перенос пересекает границы строк** — слоги из разных строк одной дорожки участвуют в одном плоском массиве. Тайминги **никогда не переносятся между дорожками** — каждая дорожка независима.

## Съёмка таймингов (`src/lib/timing.ts`)

Режим записи всегда работает с **активной дорожкой**: играет аудио, по **Space** текущее время становится `startMs` следующего неразмеченного слога активной дорожки. Указатель продвигается по порядку. `Esc` — выход. Переключение активной дорожки сбрасывает курсор на первый неразмеченный слог новой дорожки при следующем `start()`.

## `flatSyllables(lines)`

Преобразует `Line[]` в плоский массив `{ lineIndex, sylIndex, syl }` в порядке чтения. Вызывается per-track (таймлайн и съёмка передают `track.lines`).

## `nextUntimedIndex(lines)`

Индекс следующего неразмеченного слога в плоском массиве (для съёмки).
