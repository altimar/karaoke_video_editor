# Karaoke Video Editor

Браузерная утилита для создания караоке-видео — полностью на клиенте, без сервера и без ffmpeg.

Загрузите MP3 и текст песни, разбейте текст на слоги символом `/`, отснимите тайминги в такт музыке нажимая **Пробел**, настройте стиль и эффекты, посмотрите результат вживую — и скачайте готовый **MP4** с вашим аудио и закрашиваемым текстом.

## Возможности

- 🎵 Загрузка MP3 (декодируется через Web Audio API)
- ✍️ Текст песни: слоги делятся по пробелам и `/`, строки — переносами. Знаки препинания и прочие символы остаются при словах — текст читается естественно. Можно вставить текст целиком, а `/` использовать для разбивки слова внутри (например, `Ка/ра/о/ке`)
- ⏱ Съёмка таймингов: играет музыка, вы бьёте **Пробел** на каждый слог
- 🎚 Таймлайн с **перетаскиваемыми маркерами** для точной правки, перемоткой кликом и зумом колесом
- 👁 Живое превью (WYSIWYG): что видите — то и получите в видео
- 🎨 Эффекты: шрифт, размер, цвета базовый/заливки, обводка, свечение, увеличение и bounce активного слога
- 🖼 Фон: цвет, градиент или картинка
- 📐 Раскладка «Бегущая»: кинотитры, текст едет снизу вверх с постоянной скоростью, заливка стартует на центральной линии (reading line)
- 🎬 Экспорт в **MP4** (H.264 видео + AAC аудио) прямо в браузере через WebCodecs + [Mediabunny](https://github.com/Vanilagy/mediabunny)
- 💾 Сохранение/открытие проекта в JSON

## Требования

Экспорт в MP4 требует браузер с **WebCodecs API**: **Chrome** или **Edge** (рекомендуется свежая версия). Приложение само определит поддержку и сообщит, если экспорт недоступен. Редактирование и превью работают в любом современном браузере.

## Как пользоваться

1. **🎵 Загрузить MP3** — выберите файл песни.
2. В левой колонке введите текст. Слоги разделяйте `/`, например `Ка/ра/о/ке`. Строки — переносами.
3. **● Запись таймингов** — начнётся воспроизведение. Нажимайте **Пробел** на каждый слог в нужный момент. Появится красный индикатор записи. **Esc** — выйти из режима записи.
4. На таймлайне внизу перетаскивайте жёлтые маркеры для точной правки. Клик по пустой шкале — перемотка. Колесо мыши — зум.
5. Справа настройте стиль, эффекты, фон и раскладку — превью обновляется мгновенно.
6. **⬇ Скачать MP4** — рендер видео с прогресс-баром, по завершении начнётся скачивание файла `<название песни>.mp4`.

### Горячие клавиши

| Клавиша | Действие |
|---|---|
| `Пробел` (вне записи) | Пуск / пауза |
| `Пробел` (в записи) | Поставить тайминг слога |
| `Esc` (в записи) | Выйти из записи |
| Колесо на таймлайне | Зум |

## Архитектура

Ключевая идея: **одна функция `renderFrame()`** рисует кадр и используется **и** для живого превью (цикл `requestAnimationFrame`), **и** для экспорта (покадровый цикл). Это гарантирует идентичность превью и финального видео.

```
src/
  types.ts            модель данных (Project / Line / Syllable / Style)
  state/store.ts      мини-реактивный стор (subscribe/mutate)
  lib/
    textParser.ts     текст <-> слоги (split по пробелам и '/'; пунктуация остаётся при словах)
    audioEngine.ts    <audio> для воспроизведения + decodeAudioData для экспорта
    timing.ts         контроллер съёмки таймингов (Space -> startMs)
    render.ts         renderFrame(ctx, timeMs, project) — общий рендер
    export.ts         экспорт MP4 (WebCodecs + Mediabunny)
  ui/
    controls.ts       верхняя панель (загрузка, пуск, запись, экспорт, save/load)
    lyricsEditor.ts   редактор текста слева
    preview.ts        canvas-превью с RAF-циклом
    timeline.ts       интерактивный таймлайн (drag маркеров, seek, zoom)
    stylePanel.ts     панель эффектов/стиля справа
  main.ts             сборка приложения
```

### Модель таймингов

У слога хранится только `startMs` (момент начала заливки). Конец слога = начало следующего (или длительность песни для последнего). Поэтому заливка плавная, а редактирование простое: тянете маркер — меняется и старт этого слога, и длина заливки предыдущего.

### Экспорт

Без ffmpeg, без сервера:
1. `OffscreenCanvas` рисуется в разрешении проекта тем же `renderFrame`.
2. `CanvasSource` (Mediabunny) кодирует каждый кадр в H.264 (AVC).
3. `AudioBufferSource` кодирует декодированный PCM песни в AAC.
4. `Output` + `Mp4OutputFormat` + `BufferTarget` мьюксит оба трека в один MP4 в памяти.
5. Результат — `Blob` → скачивается как файл.
